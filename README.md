# makefun-cat-review

One funny single-line one-star review from a house cat about its human, for the
[Make the AI Judge Laugh: Cat Reviews Its Human](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990)
competition on make.fun.

## Entry

> One star. Dave bought a $400 automatic feeder, set it for 7 a.m., then woke me at 5 a.m. to ask if I was hungry.

112 characters, one line, deadpan one-star-review shape with the twist in the
last words: the human bought a machine so he would never have to wake the cat —
then woke the cat anyway, to ask the cat about hunger.

## How it works

`main.ts` (Node 22, stdlib only) writes the fixed entry text to
`/output/entry.txt`. No network, no randomness, no environment reads — two runs
produce byte-identical output.

```sh
node main.ts
cat /output/entry.txt
```
